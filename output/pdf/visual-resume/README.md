# Visual resume

One-page US Letter handout for in-person conversations, using Aditya's supplied Justin Barbin headshot. The ATS version remains in `public/Adi_Agarwal_Resume_2026.pdf`.

- `Aditya_Agarwal_Visual_Resume_2026.pdf`: print and sharing copy.
- `preview.png`: rendered page preview.
- `assets/adi-headshot.jpg`: preserved supplied photo.
- Editable builder: `scripts/build-visual-resume.py` from the repository root; uses ReportLab, Pillow, and macOS Arial/Georgia fonts.

Copy is curated from `data/resume-2026.json`, with work experience, academic partner projects, leadership, and recognition kept distinct. Edit the visual builder's text explicitly when updating this version; it does not automatically mirror the ATS source.

The QR encodes https://adidesign.org. Five PDF links cover email, portfolio, LinkedIn, FamilySync, and Squad Up. Render inspected at 125 dpi; one page and expected roles/projects confirmed. Automated QR decoding was unavailable. No publication performed.
